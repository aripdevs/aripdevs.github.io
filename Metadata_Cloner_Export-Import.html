Metadata Cloner

Salin EXIF dari satu gambar ke gambar lain, dan periksa apakah sebuah file membawa penanda AI. Sumber bisa dari upload gambar atau file JSON metadata (export/import). Saat memproses, semua metadata target dihapus dulu (termasuk penanda AI seperti XMP/C2PA), lalu diganti dengan metadata sumber. Semua diproses di browser Anda; file tidak diunggah ke server.

1. Sumber

Gambar/video yang metadatanya diambil, atau impor file JSON metadata.

2. Target

Gambar atau video yang metadatanya dihapus lalu diganti dengan metadata sumber.

Export / Import JSON. Setelah membaca sumber, klik Export JSON untuk menyimpan EXIF ke file .json. File itu bisa diimpor lagi lewat Import JSON metadata (tanpa perlu upload gambar sumber). Berguna untuk menyimpan profil kamera atau membagikan metadata antar sesi.

Cara kerja proses. Target JPEG: semua segmen metadata (APP0–APP15, COM, XMP, C2PA/JUMBF, IPTC, EXIF lama, dll.) dihapus, kemudian EXIF dari sumber (gambar atau JSON) disisipkan. Target PNG/WebP: di-encode ulang ke JPEG (kualitas 95) sehingga metadata asli hilang, lalu EXIF sumber ditulis. Hasil hanya berisi metadata sumber (plus orientasi/ukuran target jika opsi dicentang).

Batasan. Salin EXIF penuh bekerja untuk target JPEG/PNG/WebP (hasil selalu JPEG). Video bisa dibaca dan diperiksa di sini, tetapi menyalin metadata video butuh ffmpeg atau exiftool. Contoh perintahnya:

exiftool -tagsFromFile sumber.mp4 -all:all -overwrite_original target.mp4
ffmpeg -i target.mp4 -i sumber.mp4 -map 0 -map_metadata 1 -c copy hasil.mp4

Tentang deteksi AI. Pemeriksaan hanya membaca metadata (C2PA, XMP, teks PNG, tag EXIF). Metadata mudah dihapus atau dipalsukan, jadi hasil bersih tidak membuktikan bahwa gambar itu asli. Menyalin EXIF juga tidak membuat gambar menjadi foto kamera. Alat ini menghapus penanda AI dari target sebelum menulis metadata sumber, tetapi tidak memalsukan tanda tangan kriptografi Content Credentials.
